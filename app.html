Загрузка...

Похоже, запрос не дошёл до сервера — это не ошибка приложения.

Вероятная причина — провайдер, роутер или Wi-Fi блокируют доступ. Попробуйте сначала мобильный интернет вместо Wi-Fi. Не помогло — смените DNS на устройстве:

Android

Настройки → Сеть и интернет → Приватный DNS → Имя хоста провайдера → dns.google (или 1dot1dot1dot1.cloudflare-dns.com).

iOS

Настройки → Wi-Fi → значок (i) у своей сети → Настроить DNS → Вручную → добавить 1.1.1.1 и 8.8.8.8.

Windows

Параметры → Сеть и Интернет → Wi-Fi/Ethernet → Свойства оборудования → Изменить назначение серверов DNS → Вручную → IPv4 основной 1.1.1.1, дополнительный 8.8.8.8 (нужны права администратора).
